# Expression of need

## Context

Public buyers receive tender applications as a set of files: application forms, company registration extracts, insurance certificates, references. Before any evaluation, an officer must check that every required document is present. On a large consultation with several lots and many candidates, this check takes hours and is a common source of errors.

## Who uses the tool

- The procurement officer who opens the applications and must decide which ones are complete.
- The buyer's reviewer who confirms the doubtful cases.

## What the tool must do

1. Accept a checklist of required documents and the files of one application.
2. Read each file and tell which requirement it covers.
3. For each requirement, give a status: present, missing, or doubtful.
4. Show the evidence behind each status: which file and which passage.
5. Pause when a case is doubtful and ask a reviewer to decide.
6. Produce a final report with a clear verdict, usable in the procurement file.

## What the tool does not do

The tool checks that a document is there and relates to the requirement. It does not verify that the document is authentic, signed by the right person, or legally valid. Those checks stay with the officer.

## Success criteria

- No mandatory document reported present without evidence from the files.
- Every doubtful case stops for a human decision before the report is written.
- A review can be paused, the service restarted, and the review resumed without loss.
- An officer understands the result of a review in under a minute.
